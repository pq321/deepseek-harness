# @deepseek-ai/dsh-client-ui-settings-plugin-inventory

[English](README.md) | 中文

Web 设置中的交互式**插件列表**标签页。浏览器插件注册一个 id 为 `all` 的本地化 `settings.plugins.tab` 贡献；“插件”分区拥有导航入口与标签栏。插件激活期间不会读取 Remote；首次选择该标签页时才挂载组件，并通过 [`api-remotes`](../../api/remotes/README.md) 懒调用 `ctx.remote.pluginInventory.list()`。

该标签页把同一份可搜索清单明确分成两组。**已安装包**是 profile 依赖，标识为外部 npm、外部 GitHub 或本地安装。详情会显示当前版本与请求来源；包元数据提供仓库时链接 GitHub；本地依赖显示解析出的路径；远程包则提供一个**检查更新**操作。成功更新后会刷新清单，并在新文件需要加载时提示用户重启 DSH Web。

**运行时插件**是 Loader 条目，标识为 DSH 原生、Cordis 内置、外部或本地。详情会显示确切的模块与条目标识、可用时的包版本与仓库／路径信息、生效配置和 Cordis 阶段。无障碍 switch 会调用 `setEnabled`，使 Loader 立即热插拔并持久化重启状态。树承载条目与管理控制平面的 switch 会锁定并说明原因；如果某个已启用子条目的父级仍停用，界面会说明期望状态已保存但尚未生效。

加载、空结果、无匹配结果、通用读取失败、更新状态和启停失败状态只属于已挂载组件。清单读取失败后可以重试，且不会暴露传输细节。注册使用 `ctx.slots.inject()`，因此能跟随标签 slot 的延迟声明、重新声明、本地化变化与 teardown，而无需 import 分区拥有方。

## 模型体验

无，因为本包只在浏览器设置中展示 Host 拥有的部署快照，不注册任何模型接口。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **没有实时清单订阅** —— 标签页会在自身的包更新后刷新，并局部应用自身成功的启停结果；其他位置产生的变更只有重试或重新打开 Settings 后才会出现。
- **不安装或移除包** —— 本地包会显示源码路径与更新指引，但 profile 依赖的创建／移除和本地构建不在该标签页范围内。
